# Простое приложение для подсчета школьных расходов

# Учет финансов по ученикам

Небольшое веб-приложение для учета финансовых операций по ученикам:

-   учет **сданных денег**
-   учет **оплат**
-   справочник **учеников**

Фронтенд интерфейса сгенерирован AI,\
бэкенд реализован вручную.

Приложение запускается локально по адресу:

http://localhost:3000

------------------------------------------------------------------------

# Основные разделы приложения

В интерфейсе доступны три основные вкладки:

-   **Потраченные деньги**
-   **Ученики**
-   **Сданные деньги**

Каждый раздел работает с соответствующим REST API.

------------------------------------------------------------------------

# 1. Потраченные деньги

Раздел предназначен для учета денег, которые были переданы (например, на
мероприятия, подарки и т.п.).

## API

    /expenses
    GET
    POST
    PUT
    DELETE


## Интерфейс

### Форма добавления

Поля:

Поле         Описание
  ------------ ------------------------------------------
Дата         Дата операции

Назначение   Назначение платежа (например: Новый год)

Ученик       Выбор ученика из справочника

Sum          Сумма

Кнопка **Добавить** отправляет POST запрос в `/expenses`.

### Таблица операций

Отображаются поля:

-   ID
-   Дата
-   Назначение
-   Pupil ID
-   Фамилия ученика
-   Сумма

Дополнительно в ответе API возвращается **Balance** --- текущий баланс.

Справа отображаются:

-   **Итого (сдано)**
-   **Баланс**

------------------------------------------------------------------------

# 2. Ученики

Справочник учеников, используемый в других разделах.

## API

    /pupils
    GET
    POST
    PUT
    DELETE

## Форма добавления ученика

Поле               Описание
  ------------------ ------------------------------
Фамилия            Фамилия ученика
Имя                Имя ученика (необязательно)
Имя родителя       Имя родителя (необязательно)
Телефон родителя   Контактный телефон

После добавления ученик появляется в таблице и становится доступен для
выбора в других разделах.

## Таблица учеников

Содержит:

-   ID
-   Фамилия
-   Имя
-   Родитель
-   Телефон родителя

------------------------------------------------------------------------

# 3. Оплаты

Раздел предназначен для учета **собранных денег**.

## API

    /payments
    GET
    POST
    PUT
    DELETE

Основная таблица: `/payments`.

Дополнительно выводятся данные **ExpenseWithBalance** из `/expenses`.

## Форма добавления оплаты

Поле         Описание
  ------------ --------------------------------------------------
Дата         Дата оплаты
Назначение   Назначение платежа (например: занятие / подарок)
Ученик       Выбор ученика
Sum          Сумма

Кнопка **Добавить** отправляет POST запрос в `/payments`.

------------------------------------------------------------------------

# Логика работы

1.  Сначала добавляются **ученики**
2.  Затем можно:
    -   фиксировать **потраченные деньги**
    -   фиксировать **сданные деньги**
3.  Все операции привязываются к конкретному **ученику**

Баланс рассчитывается на основе операций расходов и оплат.

------------------------------------------------------------------------
